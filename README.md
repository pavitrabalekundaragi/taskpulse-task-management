# TaskPulse – Collaborative Task & Sprint Management

A modern, responsive task management web application developed as part of the **Thiranex Internship**. TaskPulse helps users create, organize, assign, prioritize, and track tasks through an interactive dashboard.

## 📌 Project Overview

TaskPulse is designed to simplify task management by providing a centralized platform for organizing tasks and monitoring their progress. Users can view tasks in different workflow stages, manage deadlines, filter tasks, and track productivity.

## 🎯 Objectives

- Simplify daily task management.
- Track tasks through different workflow stages.
- Organize tasks based on priority, assignee, tags, and due dates.
- Monitor task progress using a dashboard.
- Provide a responsive and user-friendly interface.

## ✨ Features

- **Task Management:** Create, view, update, and delete tasks.
- **Kanban Board:** Organize tasks into Backlog, To Do, In Progress, In Review, and Done.
- **Task Priorities:** Assign Low, Medium, or High priority.
- **Task Assignment:** Assign tasks to team members.
- **Due Dates:** Set deadlines and track upcoming tasks.
- **Search and Filters:** Find tasks using titles, tags, priorities, and assignees.
- **Checklist:** Track task subtasks and completion.
- **Multiple Views:** Board, List, Calendar, and Analytics.
- **Responsive UI:** Designed for different screen sizes.
- **GitHub Integration:** Source code synchronized with GitHub.
